# Prime Plus Builders — Corporate Website

Premium corporate website for **Prime Plus Builders And Developers Pvt Ltd**.

## Stack

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS 4
- Three.js / React Three Fiber / Drei
- GSAP + `@gsap/react` + ScrollTrigger
- Framer Motion + Lenis

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

```
/app
/components/3d
/components/sections
/components/ui
/components/providers
/hooks
/lib
/public/images
/public/models
/public/textures
```

## Content placeholders

Company facts that are not yet available live in `lib/constants.ts` as clearly labeled placeholders:

- `[PHONE NUMBER]`
- `[EMAIL ADDRESS]`
- `[OFFICE ADDRESS]`
- `[PROJECT NAME]` / `[LOCATION]` / `[PROJECT DESCRIPTION]`

Replace those values when real information is ready. Do not invent company statistics.
